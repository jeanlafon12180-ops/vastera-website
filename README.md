# VASTERA — Official Website

Official presentation website for VASTERA, an independent open-world multiplayer simulation game project.

## Contents
- Responsive French-language landing page
- Brand identity and project overview
- Feature vision, roadmap and FAQ
- Mobile navigation and accessible interactions
- Static hosting compatible with GitHub Pages or any static web host

## Run locally
Open `index.html` in a browser. No build step or package installation is required.

## Publish with GitHub Pages
1. Open the repository **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site.

## Project status
VASTERA is in development. Roblox is the planned first platform. The January 1, 2027 at 00:00 beta date is an internal target, not a confirmed release date. Features and schedule may change as the prototype is built and tested.
